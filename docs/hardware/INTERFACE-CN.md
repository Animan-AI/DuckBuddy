# 扩展板接口说明（HAT R3E、PDB/IMU R2f）

本文只写**接口**：引脚、电源、总线、尺寸。照着它可以使用我们的板子，也可以自己设计兼容的板子。
板子的原理图、PCB 和生产文件不在本仓库；需要焊好的板，请联系维护者。

## 1. 整体连接

```
                 ┌───────────── Orange Pi Zero 3W ─────────────┐
                 │  40 针排针（J1）                            │
                 └──────────────┬──────────────────────────────┘
                                │ 5V、I2S、I2C、UART（舵机总线）
          ┌─────────────────────┴──────────────────────┐
          │ HAT                                        │
          │  电源：电池 → 防反接/软启动 → 5 V 降压      │── J5  ToF（I²C，3.3 V）
          │  音频：TLV320AIC3104 codec + 功放          │── J6  喇叭
          │  舵机总线：半双工收发器                     │── J7/J8 两个驻极体麦克风（头上左右各一）
          └──────────────────┬─────────────────────────┘
                             │ J2（XH 3P）：GND / 电池 / 总线数据
          ┌──────────────────┴─────────────────────────┐
          │ PDB/IMU                                    │── J1  电池
          │  配电：TVS、各路保险丝                      │── J4  左腿 5 个舵机
          │  IMU：STM32G031 + LSM6DSV16X，总线 ID 200   │── J6  右腿 5 个舵机
          └────────────────────────────────────────────┘
     HAT 装在头里；头部 5 个舵机和 HAT 共用 PDB J5 这一路（电源和总线）
```

所有舵机、IMU、HAT 共用**一条**单线半双工总线。舵机直接用电池电压。

## 2. HAT

**外形**：65 × 30 mm，4 层板。四角各一个 Ø2.75 mm 金属化安装孔，孔中心在 (±29, ±11.5) mm，即树莓派 Zero 标准孔距 58 × 23 mm。

### 2.1 J1：接 Orange Pi 的 40 针

排母座体装在 HAT **背面**，向下插 Orange Pi。

| 针 | 信号 | Orange Pi 端 |
|---|---|---|
| 2、4 | 5V（**HAT 供给** Orange Pi） | 5V |
| 3 | 功放关断 AMP_SD | PB3 |
| 7 | I2S MCLK | PB4（I2S0） |
| 11 | codec 复位 | PB0 |
| 12 | I2S BCLK | PB5 |
| 16 / 18 | 舵机总线 TX / RX | UART7（`/dev/ttyS7`） |
| 19 / 23 | I²C SDA / SCL（codec、ToF） | PE2 / PE1（TWI2） |
| 35 | I2S LRCK | PB6 |
| 38 | I2S 数据入 SoC（codec 输出） | PB8 |
| 40 | I2S 数据出 SoC（codec 输入） | PB7 |
| 6、9、14、20、25、30、34、39 | GND | GND |
| 1、17 | 不接 | 3.3V |

Orange Pi 上的设备树配置（I2S、I²C、UART）见 `deploy/audio/`。

### 2.2 其它接口

| 位号 | 接插件 | 引脚 | 说明 |
|---|---|---|---|
| J2 | XH 3P（2.5 mm） | 1 GND · 2 电池 · 3 总线数据 | 接 PDB J5，用 3P 同向线 |
| J5 | SH1.0 4P | 1 3V3 · 2 GND · 3 SCL · 4 SDA（小圆点那端是 1 脚） | 8×8 ToF 模块。我们用 VL53L5CX，原版是 VL53L8CX |
| J6 | 焊线孔 | 喇叭 + / − | 小喇叭，单声道（功放只接左声道），TPA2005D1 功放 |
| J7 / J8 | 焊线孔 | 1 = +（P）· 2 = −（N，接咪头外壳那脚） | 头上左右两个驻极体麦克风，左 J7、右 J8 |

### 2.3 电源

- **输入**：经 J2 进来的电池电压，带防反接和软启动，F1 保险丝 3 A。
- **5 V**：LMR51450 降压（500 kHz），给 Orange Pi 和板上外设供电。3.3 V 和 1.8 V 由 LDO 从 5 V 取。
- **欠压锁定**：低于某个电压，降压芯片不启动，保护电池。

| 电池 | 启动电压 | 对应版本 |
|---|---|---|
| 3S（HL-2915 舵机） | 约 8.5 V | 3S 版 |
| 2S（HD-1910 舵机） | 约 6.3 V | 2S 版 |

两个版本的板子外观相同，用背面的"2S"标记区分。**2S 版不要装到 3S 机器人上**，否则欠压锁定会失效。

## 3. PDB/IMU

**外形**：55 × 28 mm，2 层板。

| 位号 | 接插件 | 引脚 | 说明 |
|---|---|---|---|
| J1 | 焊线孔 | 电池 + / − | 电池引线。2S 和 3S 电池用**不同插头**防插错 |
| J4 / J6 | PH2.0 3P | 1 GND · 2 V（电池）· 3 DATA | 左腿 / 右腿各 5 个舵机，菊花链 |
| J5 | XH 3P（2.5 mm） | 1 GND · 2 V · 3 DATA | 接 HAT J2。HAT 在头里，头部 5 个舵机也走这一路 |
| J2 | 排针 | SWD | 烧录 IMU 固件 |

- **保护**：TVS（SMBJ14A）；左腿、右腿、头部（含 HAT）三路各一个 4 A 保险丝，板上 3.3 V（IMU）一路 1 A。舵机拿到的就是电池电压。
- **IMU**：STM32G031 读取 LSM6DSV16X 的姿态融合结果，在总线上扮成一个飞特协议设备，**ID 200**，用硬件 DE 控制收发方向。固件见 `firmware/imu-feetech`。

## 4. 舵机总线

| 项 | 值 |
|---|---|
| 物理层 | 单线 TTL 半双工 |
| 协议 | 飞特（HLS 内存表，见 `duck-control` 的 Feetech 驱动） |
| 波特率 | **500 kbps**。A733 的 UART7 设 1 Mbps 实际只有约 750 kbps，所以统一用 500k |
| 设备 | 15 个舵机（ID 见 `deploy/robots/*.toml`）+ IMU（ID 200） |

## 5. 电池

| 机型 | 电池 | 舵机额定 | robotd 配置 |
|---|---|---|---|
| HL-2915 版 | 3S LiPo / LiHV | 9–14 V | `[battery] cells = [3]`，`max_volts = 14.0` |
| HD-1910 版 | 2S LiPo（**不要用 2S LiHV**，满电 8.7 V 超过 8.4 V 额定） | 4–8.4 V | `[battery] cells = [2]`，`max_volts = 8.4` |

robotd 开机时会自动识别电池（几节、LiPo 还是 LiHV）。插的电池和配置不符时，它拒绝上扭矩，并说明原因。
