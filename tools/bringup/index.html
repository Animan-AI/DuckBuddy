教程：这个工具怎么用、一台新机器人按什么顺序做

开始之前

  • 电脑能免密 ssh 到机器人（如 orangepi@duck-1a2b.local 或 orangepi@机器人的 IP）。启动时用 --host 指定。
  • 机器人开机、连上 WiFi 后点刷新。页头会显示主机名和 robotd 的状态；连不上时会提示，常见原因是机器人没开机、WiFi 掉了或 IP 变了。
  • 页头右边红色的全部卸力随时能按：robotd 在跑时让它 relax，没在跑时直接在总线上广播“扭矩关”。舵机乱动、发烫、冒烟时先按它，再断电。

停 robotd 不会卸力。机器人站着时先让它坐下或躺下，或者先按全部卸力，再停 robotd。

一台新组装的机器人，推荐顺序

  1. 舵机配置（装进机身之前，在“舵机”页用 USB 调试板）：逐只改 ID、改成 500k、回中后装舵盘。
  2. 板子上电体检：焊接工作室交付时按测试说明量过一遍（二极管档、短路）；舵机插座先清洗，再量 V–GND、DATA–GND。
  3. IMU 固件：新 PDB 先用 ST-Link 烧 IMU（“IMU 固件”页）。
  4. 整机测试：装好以后在“整机测试”页把六项跑一遍，全部通过再继续。
  5. 关节映射：用“舵机”页的“关节映射”卡片逐只摆动、点选关节，然后改 ID 对号或写 joint_ids（右边“关节映射”表就是配置里的 joint_ids）。
  6. 零位标定：在“零位标定”页标方向和零位，再站在 home 上精调。
  7. 最后再测一次“舵机总线”，导出报告存档。

USB 调试板

出厂舵机是 1M 波特率。OPi 的 UART7 设成 1M 时实际只有 750k，所以新舵机只能通过飞特 USB 调试板（CH343）配置。插到电脑上后，在右边选它的串口（列表里标着“CH34x”），点使用这个串口。FD 上位机开着时会占住这个串口，要先关掉 FD。

关节映射（配置里的 joint_ids）

教程：新舵机配置、装机后体检、关节映射、常见故障

A. 新舵机配置：用上面的“批量配置向导”（出厂 ID 1、1M，装进机身之前）

  1. 总览页选好 USB 调试板的串口（列表里标“CH34x”的那个；FD 上位机要先关）。给调试板接舵机电源：HD-1910 用 2S，千万别接 3S；HL-2915 用 3S。
  2. 向导里选舵机型号，它决定卸载条件和电流单位：HD-1910 写 5（0x05）、0.65 mA/格；HL-2915 写 13（0x0d）、6.5 mA/格。
  3. 选接法：
    • 串成链（推荐）：ID 顺序填 15-1。新舵机都是 ID 1，倒着分配号码，就能保证链上任何时刻只有刚接上的那一只是 ID 1，已配好的不用拔（同 tools/servo/setup_ids.py）。
    • 每只单独接：ID 顺序随意，例如 1-15；每配完一只就拔掉。
  4. 点开始，然后每一只都按提示做：
    1. 接上舵机，点接好了，检测。向导会在 1M 和 500k 上找 ID 1。
    2. 找到后自动配置：改 ID；限位写 0/4095；模式写 0（HD-1910 出厂是 4）；写卸载条件；改成 500k，上锁；最后读回核对。
    3. 第一只会让你断电重上电，确认配置真的存进了 EEPROM。
    4. 回中并保持：舵机转到 2048 并保持扭矩。这时把舵盘按中立位装上，再点舵盘装好了，松扭矩。
  5. 中途断了也不要紧，重新点开始即可：已经改过号的舵机会被认出来（“ID n 上已有舵机”），原地重配，不会撞号。
  6. 全部做完后点核对整链，在 500k 上扫一遍。
  7. 检测时可能遇到的提示：
    • “多只同时应答”：链上新接了不止一只，或者有两只都是 ID 1，多出来的那只要拔掉；
    • “之前配好的 ID 不应答”：链上有地方松了；
    • “没找到”：查电源、3 芯线方向、插头有没有插到位。

手动做也可以：在下面扫描，点一行，用“改 ID / 改波特率 / 回中”按钮，在寄存器表里改 33、9/11、19。输入框里都填十进制。回中只用于还没装进关节的舵机，装进关节后再回中，会把关节拧到中位。

B. 装进机身后的体检（机器人总线）

  1. 总览页停掉 robotd。总线选“机器人”，波特率 500k，ID 0–20，勾上“含 200”，点扫描。应该看到 15 只舵机和 IMU 板（200）。
  2. 重点看三处红字：
    • 位置红：读数超出 0..4095，是多圈计数（关节被掰过了头）。重启 OPi 清不掉，要给舵机断电。在这之前工具拒绝给它上扭矩。如果断电后关节摆到零位时的读数仍然靠近 0 或 4095，就用下面 D 的“当前位置设为中位”把跳变点挪走。
    • 状态非 0：舵机报了过压、欠压、过热或过流，看电池和温度。
    • 缺 ID：先查那一路的线和插座（PDB 插座焊完要清洗助焊膏，残留会导电），再查是不是 ID 撞了。
  3. 电压列可以顺便看电池：2S 满电约 8.4 V，3S 约 12.6 V。

C. 关节映射：装的时候没按 ID 顺序装

  1. 机器人平躺或托在手里、腿悬空。接机器人总线（先停 robotd）或者 USB 调试板（接到机器人的舵机总线上；主控开着的话 robotd 同样要停），下面“总线 / 波特率”选好（装好的一般是 500k），舵机型号选对（决定电流单位和限流）。
  2. 点扫描并开始：扫 ID 0–39，然后从最小的 ID 开始摆 ±8°。看哪个关节动了，在关节表里点它，下一只自动开始摆。没看清点再摆一次；点错了就点上面那只的 ID 标签，重摆后点正确的关节（原来占着那个关节的 ID 会退回待认）。点到一半刷新页面也不丢。
  3. 15 个点完后点左右对照核对：两腿同名关节先左后右各摆一次，颈、头、嘴逐个摆，正在摆的关节按钮会框出来。左右最容易看反（小白标定时单看一只看错过四次），这一步别省。
  4. 然后二选一：
    • A. 改 ID 对号：选目标顺序（关节顺序 1–15、同小白、配置里现有的、或自定义），点改 ID。会先把要改的舵机全部挪到临时号 160 + 新 ID，再落到新 ID，所以两只互换也行。万一中途断了，扫描时看到 16x / 17x 的就是临时号，减 160 就是它该去的 ID。改完把新顺序写进配置（在机器人总线上做的可以直接点按钮写）。
    • B. 不改 ID：把显示的 joint_ids = [...] 写进机器人配置（先备份成 .bak-时间）。在 USB 调试板上做的，就把那一行抄进 toml 的 [bus]。
    写完都要重启 robotd 才生效。joint_signs / joint_offsets 是按关节存的，和 ID 无关，映射之后照常去零位标定页标。

C2. 单只摆动测试

  1. 机器人托在手里或平躺，腿悬空不受力。点一行，限流默认 400 mA、摆幅 ±6°，点摆动测试，在弹窗里确认。
  2. 看实机哪个关节动了，和“关节”列对一下。整台对不上用上面的“关节映射”卡片；只差一两只也可以在这里改 ID 互换。小黑的颈 pitch 和头 pitch 就是靠这一步找出来、和小白反过来的。
  3. 结果里的“目标 → 实际（误差）”应在 ±2.5° 以内。下方小图里蓝线是位置、橙线是电流。到不了位：先看 44（目标电流）和 46（速度）是否被写成 0，再看是不是机械卡住。
  4. 方向（正转是哪边）不在这里看，到零位标定页逐个关节核对。

D. 当前位置设为中位（舵机自带的位置校正，EEPROM 31）

  • 作用：把舵机现在的位置记成 2048，以后读数 = 原始读数 − 偏置（mod 4096）。读数在 0 / 4095 之间的跳变点会被挪到输出轴背面，目标位置也会跟着一起平移。
  • 用途：舵盘没对着中位装的舵机，或者装好后关节零位的读数靠近 0 / 4095 的舵机（像小黑头 roll 读到 4140 那种），不用拆舵盘：关掉扭矩，用手把关节摆到零位，点一行，再点当前位置设为中位。
  • 代价：已经标过零位的关节，这一只的 joint_offsets 作废，要到零位标定页重标（重标后这一只的偏置应接近 0）。
  • 实测（10-31，HL-2915，固件 3.45）：写 31 后断电仍在；手转过原来的跳变点读数连续；回中和摆动都按新坐标到位。STS 系列的“写 40 = 128”一键校正在它上面没反应。HD-1910 还没测过，第一次用先拿一只备用舵机在台架上试。

E. 常见故障

  • 上了扭矩但纹丝不动、电流 0：44（目标电流）或 46（速度）是 0。HD-1910 有时还会“零电流卡住”，重写 46 就能动。工具每次写目标都会把 42..47 一起写。
  • 跑着跑着没力、扭矩开关还是 1：过流卸载，把 19 的 bit3 关掉（HD-1910 写 5）。
  • 电流显示比实际大 10 倍或小 10 倍：上面“电流单位”选错了。HD-1910 是 0.65 mA/格，HL-2915 是 6.5 mA/格。
  • 改波特率后找不到舵机：给舵机断电重上，再按新波特率扫描。

新舵机批量配置向导（USB 调试板）

一只一只接上：改 ID、配 EEPROM、改成 500k，再转到 2048 装舵盘（舵机自己的“零位”）。装进机身后的关节零位在“零位标定”页做。

关节映射（装好以后：哪个 ID 装在哪个关节）

一只一只摆，看哪个关节动了就点哪个关节。15 个都点完后，可以把舵机的 ID 改成想要的顺序，也可以直接把映射写进配置的 joint_ids。 用的是下面“总线 / 波特率”选的那条总线；机器人总线要先停 robotd。左右指机器人自己的左右。

摆动：以当前位置为中心 ±摆幅、回原位后松扭矩；跨 0/4095 的一侧跳过；过流（默认 1.5 A）或偏离 15° 立即切扭矩。 回中：转到同圈最近的 2048 并保持扭矩，装好舵盘再松——只用于还没装进关节的舵机。读数超出 0..4095（多圈）一律拒绝上扭矩，要断舵机电。
教程：零位标定（joint_signs / joint_offsets）

标定页（下面嵌着的就是 tools/joint_align）把实机关节角实时套到训练用的模型上，让你对照模型核方向、记零位。 标的结果是 toml [bus] 里的两行：joint_signs（每个关节正转是哪个方向）和 joint_offsets（零位时的编码器读数减 2048）。

准备

  1. 舵机总线体检通过：15 只都应答，没有多圈读数（位置红）。
  2. 总览页启动 robotd。
  3. 机器人平躺或托在手里：点开始标定后全身会卸力。

第一步：核方向（扭矩关着，用手掰）

  1. 在表格里点一个关节，看第三张图里这个关节的正方向往哪边转。
  2. 用手把实机的这个关节往同一个方向掰，前两张图里的模型应该同向转，读数变大。
  3. 方向反了就点这一行的反向（立即生效），再掰一次确认。
  4. 15 个关节逐个做一遍。左右成对的关节最好两边同时掰，只掰单只容易看反。嘴没有模型：张嘴时读数应变大。

第二步：记零位

  1. “参考”选零位，照着参考图把机器人摆好（腿伸直、头摆正）。
  2. 全身摆好后点全部设为零位，也可以选中某个关节点所选关节设为零位。嘴要闭到底再设零位。
  3. 点写入配置：先备份（*.bak-时间），再改 的这两行，然后重启 robotd。

第三步：站在 home 上精调

  1. 托好机器人，点写入并回 home：robotd 重启（不断扭矩），机器人平滑地回到站姿 home。
  2. 放到桌面上，检查以下几点：
    • 脚底贴平；
    • 躯干俯仰、横滚接近 0（页面上方有 IMU 读数；用手机水平仪量一下躯干，核对 IMU 准不准）；
    • 头和地面平行；
    • 脚尖朝正前；
    • 左右对称；
    • 能自己站住。
  3. 哪个关节偏了，就点那一行零点两边的−/+（每次 0.5°，在同一个指令角下让关节往负 / 正方向多转），再点写入并回 home看效果。
  4. 经验（小黑 10-25）：
    • 脚平以后躯干还前倾：按小腿、大腿的实际角度反算髋、膝、踝的修正量。
    • 躯干平了却往后倒：脖子和头的后仰角度不对，量一下再修。
    • 修完仍往后倒：说明实机重心比模型靠后，要改训练模型，不要再动零位。
  5. 改过、还没写入的值显示成橙色。撤销改动回到 robotd 现在用的值。
复用 tools/joint_align：实机关节角实时套到训练模型上渲染；每个关节可"反向"、"设为零位"、±0.5° 精调， "写入配置"会先备份再改机器人上 的 joint_signs / joint_offsets， 然后 ；"写入并回 home"再执行 。
需要 robotd 在跑。第一次连上会发 robot.relax（全身卸力），所以先让机器人躺好或托好。 零位参考：大腿、小腿、躯干按页面里的"零位参考"图摆；站在 home 上时脚底贴平、IMU 躯干俯仰≈0。
教程：给 PDB 上的 IMU 板烧固件

PDB 上的 STM32G031 + LSM6DSV16X 跑 firmware/imu-feetech，在舵机总线上伪装成飞特设备 ID 200（500k），robotd 每拍连同 15 只舵机一起读。 新焊的 PDB 出厂是空片，要先烧一次；固件改了也在这里重烧。

接线

  • ST-Link 插电脑。第一次用要先用 Zadig 给它装 WinUSB 驱动，否则 probe-rs 找不到。
  • 接 PDB 的 J2：1 SWDIO、2 SWCLK、3 GND、4 3V3。PDB 已经由电池或电源供电时，3V3 可以不接。
  • ST-Link 的 10 针座（Zave）：2 SWCLK、4 SWDIO、6 GND。

步骤

  1. 1. 构建：cargo build --release。左边的“构建产物”会显示是否比源码旧，“未提交改动”不为空时说明烧的不是某个提交的版本。
  2. 2. 找 ST-Link：probe-rs list，输出里要有一行 ST-Link。显示 “No debug probes were found” 时，查 USB 线和 WinUSB 驱动。
  3. 3. 烧录：probe-rs download --verify 加 reset。输出最后应该是“完成”。
  4. 4. 经总线核对（先在总览页停 robotd）：通过的标准：
    • 型号 0x16D6，固件版本和源码一致；
    • 融合输出约 120 Hz，标志 = 3；
    • 平放静止时陀螺噪声 < 1 dps；
    • 俯仰、横滚和机器人的实际姿态吻合。

烧不进去

  • 连不上芯片（SWD 读不到、J2 的 SWDIO 是 0 V）：先查 U1 方向，圆点应在左下，第一块 PDB 就是焊反了；再查 PDB 有没有供电、J2 的线序。
  • 烧完总线上没有 200：查 PDB 到 HAT 的总线线束；确认 robotd 配置里 [bus] imu = true。IMU 必须排在 SYNC_READ 的最后，robotd 已经是这样排的。
  • 俯仰、横滚的轴对不上：IMU 的安装方向由 [bus] imu_axes 决定（小黑、小白都是 "y,x,-z"）。核对方法是把机器人仰躺，看重力落在传感器的哪根轴上。

固件 firmware/imu-feetech

ST-Link 插电脑，接 PDB 的 J2（1 SWDIO、2 SWCLK、3 GND、4 3V3；PDB 已上电时 3V3 可不接）。 Windows 上 ST-Link 要先用 Zadig 装 WinUSB 驱动。新焊的 PDB：U1 圆点在左下，焊反了 SWD 读不到。
